# 0.17.4

Authorized clients can inspect an exact original Slack submission through the existing management API. The response separates Slack delivery evidence from last observed Instance receipts and accepted-work references, including multiple work records linked to one source. A lost response can be investigated without sending the original input again.

Compatible Agent Instances receive the original source revision and attribution through the negotiated input-continuity profile. Context binding remains limited to the configured grant; plain ACP endpoints continue to work and unsupported or unknown receipt coverage stays explicit. Existing credentials, session bindings, work and delivery records are preserved.

This patch keeps the same dependency selections and native installation/update behavior. Downloads remain unsigned previews. See [exact submission lookup](../harness.md#inspect-an-original-submission) for the exact interface and its limits.
