# 0.16.2

Slack conversation reads include table contents that Slack omits from its plain
text fallback. Agents can use the original handoff's rows without asking someone
to repeat them. Existing fallback prose and message identity remain unchanged.
Reads share the existing 16,000-character total budget; the redundant
2,000-character cutoff on each message is removed. Truncation remains explicit.

Outgoing replies preserve code data placed on the opening fence line instead of
letting Markdown rendering mistake it for a language label. Valid language fences
still work; multipart replies retain the original saved content and delivery IDs.

These are content-preservation changes. They do not replay old messages, rerun
work, create follow-up prompts, or change permissions and delivery policy.
