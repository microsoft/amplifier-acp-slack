# 0.16.1

Completed peer handoffs no longer wait for a person to send another message.
The connector removes its separate peer-reply count and human-response gate;
ordinary reply pacing, source and audience checks, Stop, and uncertain-delivery
handling still apply. The old peer-limit settings remain readable for existing
configurations but no longer control delivery. The obsolete preference is removed.

A successfully settled continuation of accepted work can finish quietly. It no
longer requires a public acknowledgment or produces a connection-failure notice
because the agent has nothing useful to say. Missing answers to direct requests,
failed transports and unsettled tool effects remain distinct outcomes. Quiet
completion of a turn does not certify completion of the underlying work.

Existing sessions, work, source records and delivery receipts are retained.
Upgrading does not replay failed work or retry uncertain sends.
