# Slack Connector 0.17.14

Ask your agent to attach its saved document. A compatible agent can send
Markdown, plain text, CSV or JSON as a Slack file with its original name and
contents. Agents with the connector’s conversation tools can also attach
contents directly to their current reply. The connector shares the files in
that reply’s Slack thread.

An agent can read a Slack-hosted text attachment on an earlier message in its
conversation. The reader returns consecutive pages with byte offsets and a
checksum so it can retrieve the last line of a longer document.

The default is four files per reply. Connections can configure one to eight
files within their existing byte limits. **Check file access** in connector
settings shows whether Slack granted that installation file access.
