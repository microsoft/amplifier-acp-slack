# Slack Connector 0.17.13

In busy Slack threads, the connector can now give the agent one copy of each matching message. When conversation history already contains a message, the orientation points to its channel, message ID and revision. The connector keeps the excerpt when the source, author, revision or text differs. With Agent Instance 0.22.13 or later, the connector and Instance can also agree to supply the thread orientation once while retaining scoped memory and work.

Two valid quiet responses after mid-turn updates previously ended as `invalid_answer`. An ambient decision can now finish with reasoning alone after its tools and callbacks settle. A final `pass` decision can also carry `text: null`. Both finish quietly without sending a Slack reply. Unsettled tool activity and malformed answers still surface as failures.
