# Slack Connector 0.18.3

Native connector status on macOS reads the service's top-level launchd properties.
Previously, nested resource and jetsam coalition fields could be mistaken for
duplicate service properties, leaving a started connector's status unverified.
The corrected parser keeps service identity, process-generation and profile
checks intact, rejects malformed observations, and preserves braces inside
arguments as data.

The native-platform dependency also includes the accepted Windows hostname
lookup and hidden startup-utility launch corrections. This release changes the
native-platform pin and package version; Slack authorization, settings,
credentials, conversations, request budgets and uncertain-operation handling
remain unchanged. It does not restart or repair an existing installation by
publishing a package.

The proved local HTTP readiness correction from 0.18.2 remains included. Native
package qualification uses disposable installations; live Slack workspace
approval, first-message delivery, personal desktop acceptance and private Mac
signing are separate checks. Previously published 0.18.2 files remain unchanged.
