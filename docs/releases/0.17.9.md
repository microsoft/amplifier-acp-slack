# 0.17.9

Approval requests are easier to read in Slack. The private review view leads
with the agent's explanation and readable fields. Remaining technical details
are still available, with a notice when long content has been shortened.
Detailed arguments and location fields remain in the private review view.

Shorter buttons make common choices easier to scan: **Allow this request**,
**Deny**, and **Always allow this** when offered by the agent. Custom choices
remain distinguishable, and their full wording stays in the private review
view. The displayed deadline says how long you have to answer; it does not
describe how long a granted permission lasts.

The connected agent still owns remembered-rule scope and revocation. Slack
returns the exact selected option to the same live request, and existing
requester, workspace, app and message checks remain in place. Expired or
withdrawn requests cannot be revived by a late click. A recorded approval does
not establish whether an action completed.

This update changes no approval setting, execution budget or connection
credential. Native downloads remain unsigned.
