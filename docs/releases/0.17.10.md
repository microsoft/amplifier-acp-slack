# 0.17.10

**View request** now explains privately when request details belong to someone
else, instead of appearing to do nothing. This also works on closed approval
cards. Request contents and the recipient's identity remain private.

If Slack cannot open the window, the connector attempts one private notice to
the person who clicked. It does not retry a failed delivery or change the
request's decision. The original recipient can still inspect closed requests.

Existing requester, workspace, app and message checks remain in place. This
update changes no approval setting, Always rule, credential or execution budget.
Native downloads remain unsigned.
