# Slack connector 0.17.11

Permission choices now say **Remember matching action** and **Block matching
action**, making clear that a rule applies to matching requests rather than every
command. The request explains how **Automatic** in the agent’s approval settings
stops individual approval prompts when supported.

Completed approval cards are shorter and keep their private **View request**
button. A decision records permission; it does not claim that an action ran.
This release changes presentation only: request identity, choice IDs, approval
authority and private-details access are unchanged. The private feedback correction
from 0.17.10 remains included.
