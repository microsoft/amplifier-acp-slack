# Slack Connector 0.17.15

In an eligible group conversation, the connector advertises the same owner-message tool whether a person or another agent started the turn. Engines that use the tool list to identify reusable context can keep using that context as speakers alternate.

Sending an owner message still requires a qualifying human-started turn and the existing owner, channel, and direct-message checks. An agent-started attempt receives a refusal before the connector opens a conversation or queues a message.
