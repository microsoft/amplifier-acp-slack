# Slack Connector 0.18.4

A strict TLS client could reject a connector-managed HTTPS listener with
`Missing Authority Key Identifier`, even when it trusted the connector’s CA.
Newly issued server certificates now include the issuing CA’s key identifier.

Existing installations keep their current certificate until renewal. If a
client encounters this error, follow the [managed certificate renewal
procedure](../installation.md#renew-an-older-managed-https-certificate) to
issue a new leaf under the same CA and review any configured leaf fingerprint
pins. Clients continue to verify the CA and hostname.
