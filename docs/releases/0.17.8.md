# 0.17.8

When the connected agent withdraws a pending approval, Slack closes that request's
card and removes its decision buttons. The conversation can keep running and
present another approval without waiting for the withdrawn request to expire.
This also applies to approval requests during session setup.

Withdrawal must identify the exact pending request. An unrelated cancellation or
a late click cannot approve it or affect a newer request. A decision already
recorded is preserved; withdrawal does not undo an action or establish whether it
ran. If Slack cannot refresh the card, its stale buttons still cannot approve the
withdrawn request.

Single-request and remembered choices remain bound to the original person,
workspace, app, message and live request. Approval settings, execution budgets and
question handling are unchanged. Remembered policy remains the connected agent's
responsibility; this patch changes no installation setting. Native downloads
remain unsigned.
