# 0.17.1

Open Slack Connector on Windows, Mac or Linux without installing developer tools or system Python. Native downloads include the private setup runtime, first-account browser flow and optional current-user startup.

Independent native installations can check published bundles, defer during active or uncertain work, and recover or roll back application files without rewinding conversation evidence or credentials. Existing Linux PAM/HTTPS and externally enrolled update ownership remain unchanged. The side-conversation behavior introduced in 0.17.0 is retained.

See [native installation and recovery](../native-installation.md) for the setup flow and platform limits. These preview packages are unsigned and unnotarized. Slack workspace authorization, platform approval and an independently configured ACP agent remain separate prerequisites; installing the app does not send messages or start a model. Windows 11 ARM uses the official Slack CLI's x64 compatibility, while the connector and its private Python run natively as ARM64.
