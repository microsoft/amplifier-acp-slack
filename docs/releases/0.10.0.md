# 0.10.0 — Keep revised replies, referenced errors, and reactions coherent

A revised silence decision now completes quietly without concatenating earlier drafts or replaying tools. Interleaved messages remain separate. Error replies expose a safe failure stage and reference.

Thread context retains the exact error/status root a person discusses while unrelated controls stay filtered. Authorized current reactions are readable; the agent can add or remove its own reactions in the current conversation. Reaction events become bounded active-turn observations, never new work or approvals. Existing Slack installations must approve reactions:read and reactions:write and subscribe to reaction_added/reaction_removed before using those capabilities.

Validation: Rust context/access/dedup regressions, real-process revised silence and reaction awareness fixtures, streaming/status/media checks.
